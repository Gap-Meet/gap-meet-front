## 우리 빈칸만남, 이럴 때 사용해요!

**일회성 만남**은 물론, **주기적인 만남**까지 모두 조율하고 관리할 수 있어요.

1. 두 세명이 아니라 **인원이 많아서** 일정 조율하기가 복잡해요!
2. **주기적으로 만남**(팀플, 스터디, 취미 모임, 지인과의 약속 등) **시간**이 필요해요!
3. **이제 약속 시간 정하는 걸로 머리 아프고 싶지 않아요!**

## 빈칸만남만의 특별한 점은?

### 나만의 시간표는 기본!

나만의 시간표에 일정을 추가해 **나의 일정을 관리**할 수 있어요.

### 모임시간을 자동으로 정해줘요!

특별한 **알고리즘**을 통해 눈으로 직접 빈칸을 찾거나 생각할 필요없이 **자동으로** 구해줘요.

### 무려 모임시간을 3개나 랭킹으로?

모임 페이지에서 모임 시간 정하기 버튼을 누르면 **만날 수 있는 인원을 고려해 랭킹**으로 알려줘요.

### 모임시간을 구할 때, 옵션을 선택할 수 있어요.

평일/주말, 시간제한, 최소시간 충족 총 **세 가지의 옵션**을 선택하여 모임의 성격에 따라 모임 시간을 조절할 수 있어요.

### 선택한 모임 시간의 날씨와 장소를 추천해줘요.

모임 날의 **날씨**와 모임의 성격(공부, 친구와 약속 등)과 만남 지역을 입력하면 **주변의 좋은 장소**를 알려줘요.

### 모임 목록에서 여러 개의 모임 관리가 가능해요!

**모임 이름**과 **비밀 코드**를 사용해 모임에 참여했다면, 모임 목록에서 참여한 모임들을 볼 수 있어요. 자신이 **방장**인 모임은 **왕관 표시**👑로 구분 가능하답니다.
